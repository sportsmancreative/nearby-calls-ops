# How to start a Nearby Calls onboarding

For Sarah and Lisa. You don't need to know anything technical. Claude keeps the notes and saves everything for you.

## The first time (once)
1. Go to **claude.ai** and sign in with your Sportsman Creative work email.
2. Click **Code** in the left sidebar.
3. Check the box at the top of the message area says **nearby-calls-ops** and the environment says **NC Onboarding**. If not, click them and choose those. (Jordan sets these up, so they should already be there.)

## Every time
1. Go to **claude.ai > Code** and click **New session** (top left).
2. Make sure it says **nearby-calls-ops** and **NC Onboarding**.
3. Type what you want, in your own words. For example:
   - "Start onboarding a new client: Smith Plumbing. Here's what I know: ..."
   - "Where are we with Irwin Benefits?"
   - "Cody sent his info, here it is. What's next?"
   - "What's waiting on clients right now?"
4. Claude tells you one step at a time, with the exact buttons to click in GHL. Do the step, then tell Claude "done" (a screenshot helps if something looks different).
5. When you're finished for now, say **"Save and wrap up."** Claude updates the client's file and tells you what's waiting.

## A few rules
- **Never paste a client's EIN, Social Security number, or passwords into Claude.** Type those straight into GHL.
- Claude writes messages for clients, but **you** decide when to send them. Read them first.
- Don't promise clients rankings, a number of calls, or a number of reviews.
- Not sure? Ask Claude. Still not sure? Ask Jordan.

## Good to know
- Each session starts fresh, but Claude reads the client files and playbook every time, so nothing gets lost as long as you end with "Save and wrap up".
- You and the other person can work on the same client. The notes stay shared.
- Texting registration takes about a week, so it's always the first thing to start.
